# Python Banking System

## About the Project

I made this Banking System using Python lists, dictionaries, file system, etc.

In this program, the user can create bank accounts, check balances, deposit and withdraw money, manage beneficiaries, and record transactions. I also added JSON file storage so that account details, balances, and beneficiary information are saved. So, whenever the user closes the program and reopen then the data is loaded again where user had left off.

While working on this project, I also started exploring how the transaction data could be used for data analysis. Since transaction details are stored in JSON format, they can be loaded into a Pandas DataFrame and explored further.

## Useful Features

- Create and manage bank accounts
- Check account details and available balances
- Deposit and withdraw money
- Add, view, and delete beneficiaries
- Store account information and transaction records in JSON files
- Keep saved account information available when reopening the program
- Load transaction data into Pandas for further analysis

## Technologies Used

- **Python** — For the banking logic and program functionality
- **JSON** — For saving account details and transaction records
- **Pandas** — For loading transaction data into a DataFrame and exploring it

## How Data Science Connects to This Project

One thing I found interesting while building this project was that the data generated by a Python application can be useful beyond the application itself.

Each transaction can contain information such as the amount, transaction type, status, date, and current balance. By loading these records into Pandas, I can explore questions like:

- Which transaction types occur most frequently?
- What is the highest transaction amount?
- What is the average transaction amount?
- Which user do most of the transactions?

I have started working with this data in Pandas and plan to improve the analysis further as I learn more about data visualization and exploratory data analysis (EDA).
